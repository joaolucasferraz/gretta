# GRETTA

Site institucional da GRETTA, com apresentação da marca e conceitos de roupas de tricô para cães.

## Visualizar

Abra `index.html` em um navegador. O site é estático e não precisa de instalação ou compilação. As imagens estão na pasta `assets`.

## Contato

Os links de Instagram e WhatsApp estão no arquivo `index.html`.
